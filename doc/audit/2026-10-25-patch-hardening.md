## 功能与边界

| 范围 | 最终行为 |
| --- | --- |
| 便携存储 | 新安装默认使用程序旁的 `tdl-ui-data`；已有旧版数据时继续使用原目录；支持绝对路径的 `TDL_UI_DATA_DIR`。不会静默复制会话或换目录存储。 |
| 数据保护 | 数据目录有进程锁。新建 Windows 数据目录使用当前用户、SYSTEM、Administrators 的继承 ACL；保留已有目录权限。配置原子写入，界面设置不能覆盖后端维护的账号归属和脚本元数据。 |
| 窗口退出 | 默认每次询问；可记住保留数据或清理默认媒体缓存。清除应用数据不能记住，必须逐次确认，后端另有原生确认。 |
| 清理范围 | 退出缓存清理仅处理默认缩略图、预览与视频分段。重置只处理列出的应用文件和目录，保留下载文件、外部自定义目录与数据根目录中的未知文件。会核验当前和历史下载目录，重叠时拒绝。 |
| 自定义缓存 | 不接管已有无本应用标记的非空缓存子目录。旧配置中与应用数据目录重叠的自定义目录会阻止重置；先迁移内容到外部独立目录。不会通过保存设置偷偷遗忘尚有内容的旧目录。 |
| 会话切换 | 登录、导入、注销与下载/媒体查询通过会话使用锁互斥；关闭旧连接并清理内存快照。联网后校验实际账号与记录归属一致。 |
| 媒体身份 | 账号、私聊/普通群组/频道命名空间、对话和消息分别校验；超级群组归频道命名空间。缓存、已下载标记和清单均按来源隔离，收藏夹单独标识。 |
| 全选与扫描 | 全选当前筛选结果与下载整个对话区分处理；整个对话从最新消息开始。分页去重并检查游标前进；取消、失败、达到 100000 项上限都不会冒充完整结果。 |
| 下载预检 | 单项、选中和整个对话共用确认窗口；清单跳过与本地已有不重复计数。普通自动跳过要求来源一致且本地 SHA-256 摘要匹配；无法确认的重名继续下载并编号。 |
| 文件保存 | 限制相对输出路径、设备保留名与链接越界。每次使用独立临时文件；完整长度、刷新磁盘与后处理成功后才发布。并发下载与发布时撞名不会静默覆盖普通下载文件。 |
| 批量重下 | 创建仅包含所选消息的新任务，关闭相册展开，原任务及断点保留。只允许已完成项覆盖登记的最终目标；跳过/失败项遇到重名时编号保存。无账号或对话类型的旧记录不猜测来源。 |
| 清单 | 本地目录扫描只导出确认匹配项；重名需核对具体消息时间、字节大小和文件，并逐条明确确认。导出前重新检查本地文件，零匹配不生成文件。 |
| 清单追加 | 新格式为 v3 JSONL，逐条追加、同步写盘并使用文件锁协调不同应用实例。兼容旧 JSON 中有效的确认记录。中断产生的无效尾记录不计为完成，后续写入前修复；失败、取消与临时文件不追加。 |
| 脚本 | 初始化和契约调用都有超时保护；解释器超时后停止并禁用此脚本全部契约函数。限制导入、后台 goroutine、文件枚举及不可取消的等待接口；脚本没有文件、网络或子进程 API。 |
| 日志与性能 | 性能指标只保存在本地；日志目录失败不偷偷换到系统缓存目录。代理 URL 中的账号密码脱敏；可写探针不覆盖固定文件。修复预加载空结果误判命中、缓存统计竞争和缓存后台清理生命周期。 |

“恢复”保留同一任务中完整保存的文件记录，未完成文件重新下载；当前没有单文件字节级分片续传。清单可在本地媒体移走后继续作为明确的跳过记录；它不能证明外部上传已经完成。

## 隐私与安全审查

审查涉及启动、网络调用、会话读写、缓存、输出路径、脚本解释器、日志及子进程入口。本次没有加入遥测上传、远程控制、自动更新、系统自启动项、计划任务或后台常驻服务。正常业务网络来自 Telegram 客户端及用户配置的代理；外链由用户点击后交给浏览器。

退出清理助手是**同一个可执行文件的短时子进程**，仅在已确认的重置后使用：等待主进程释放数据锁，再重试 WebView 文件句柄释放后的清理。它不启动另一个 WebView、不建立 Telegram 连接、不安装持久后台组件；清理目标根据允许列表重新生成，不执行记录文件指定的任意路径。

缓存和清单中的媒体身份、文件名、时间与本地路径仍属于本地隐私数据，应按个人文件保管。重置是逻辑删除，不是 SSD、系统备份或取证级安全擦除。本地注销/重置也不等于撤销 Telegram 服务器上的设备授权；导入 Desktop 会话不会主动注销 Desktop。

源码检查与漏洞扫描不能证明所有第三方代码绝对没有后门，也不能保证任何环境下绝无 bug。脚本仍是进程内解释执行，不构成操作系统级 CPU/内存隔离，默认内置脚本不启用。
