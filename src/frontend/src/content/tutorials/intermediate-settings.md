# 代理与设置

难度：中级

「设置」页集中管理网络、下载与界面选项。修改后点击「保存设置」生效。

## 账号

显示当前登录状态，提供「账号管理」/「前往登录」快捷入口。

## 网络

### 使用代理

总开关控制是否启用代理功能，默认开启。关闭后所有网络请求直连，不经过任何代理。

### 代理模式

总开关开启时，两种模式互斥二选一：

- **使用系统代理**（默认）：读取操作系统代理环境变量（`HTTPS_PROXY` / `HTTP_PROXY` / `ALL_PROXY`），适合 Clash、v2ray 等代理工具已配置系统代理的场景
- **自定义代理**：手动填写代理地址，支持 SOCKS5 与 HTTP 代理：

```
socks5://127.0.0.1:1080
socks5://user:pass@127.0.0.1:1080
http://127.0.0.1:8080
```

代理对**登录流程和新创建的任务**生效；修改代理不影响进行中的任务。

## 下载

### 默认下载目录

创建任务时未指定目录时的默认保存位置。默认值为用户主目录下的 `Downloads/tdl-ui`。

### 文件命名与重名处理

普通下载默认按原始文件名保存，仅清理 Windows 不允许的字符。按原名、字节大小和明确来源比对，确认已有的媒体才跳过。无法确认的重名媒体继续下载，实际保存名自动追加 (1)、(2)，不覆盖已有文件。原始文件名和实际保存名的关联会保留。

清单扫描中同名文件默认不进入名单；仅在确认与消息匹配后才收录。
### 磁盘使用率上限

默认 90%，可设为 1%–99%。保存后对下次启动或恢复的任务生效，依据实际下载目录所在磁盘的整体使用率判断。达到上限或下一次写入将超限时停止下载，等待文件收尾后完成本次任务，并显示原因和清单路径。文件保存或清单写入失败时仍显示失败。

完成项追加至所选清单；未选清单时，自动在下载目录按对话生成清单并逐条记录。清理空间后，导入清单、重新选择原下载范围即可跳过已完成项，继续剩余下载。未完成的临时文件不会记入清单。

### 性能参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 单文件线程数 | 4 | 单个文件的并行分片数，大文件可调高 |
| 并发文件数 | 2 | 同时下载的文件数量 |
| DC 连接池大小 | 8 | Telegram 数据中心连接池，一般无需修改 |

> 参数过大可能触发 Telegram 限流（FLOOD_WAIT），建议保持默认或小幅调整。

## 界面

主题支持 **亮色 / 暗色 / 跟随系统** 三种模式：

- 选择后立即生效并持久保存
- 「跟随系统」模式会自动响应操作系统的主题偏好变化
- 左侧导航栏底部的 {{icon:theme-dark}} / {{icon:theme-light}} 按钮可快速在亮/暗之间切换

### 日志显示

| 参数 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| 日志字体大小 | 14px | 10–28 | 日志页字号，Ctrl + 滚轮亦可调整 |
| 滚动条尺寸 | 10px | 6–24 | 日志页滚动条宽度 |
| 最大滚动行数 | 128 | 16–1024 | 日志页保留的最大行数，超出后最老的数据被清除 |

## 存储

### 缓存目录

缩略图与预览缓存的存放位置，保存后立即生效。默认值为 `<数据目录>/cache`。

### 视频临时目录

在线视频边下边播的分段暂存位置，上限 2GB 自动清理（按 mtime LRU 淘汰），保存后立即生效。留空回落 `<数据目录>/tmp`。

### 清空缓存

删除缓存目录下的缩略图、预览文件与视频临时分段，不影响已下载的内容（二次确认）。

## 日志

### 输出目标

- **仅文件**：日志仅写入文件
- **仅界面**：日志仅在日志页显示
- **两者**：同时写入文件和界面显示

### 日志级别

DEBUG / INFO / WARN / ERROR，保存后立即生效，低于该级别的日志将被丢弃。

### 日志目录

默认为应用数据目录下的 `logs` 子目录，支持自定义。目录不可写时只保留界面日志，不自动改写到系统目录。

### 格式模板

可用占位符：`{datetime}` `{level}` `{module}` `{file}` `{func}` `{line}` `{msg}`，留空使用默认格式。

### 滚动策略

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 单文件上限 | 100 MB | 单个日志文件最大尺寸 |
| 保留天数 | 30 天 | 日志文件保留天数 |
| 保留文件数 | 10 个 | 最多保留的日志文件数量 |

### YAML 配置

支持导入 / 导出 YAML 格式的日志配置。数据目录下的 `logging.yaml` 会在启动时自动加载；导入后立即生效无需保存。

## 数据目录

设置页底部显示应用数据目录的实际路径（新安装默认为程序旁的 `tdl-ui-data`，旧安装保留原目录），包含 `config.yaml`、会话存储 `kv/`、任务数据库 `tasks.db`、缓存 `cache/` 和脚本目录 `scripts/`。


## 同名策略、便携目录与退出清理

原名比对确认已有的媒体才跳过，未确认的重名文件自动编号保存。扫描导出的清单只包含本地实际存在且确认匹配的媒体，历史记录中的已删除文件不会混入新扫描。已保存清单不依赖本地文件是否仍在，后续导入可继续跳过。

旧数据不会静默复制到新位置。手工迁移前先关闭应用，再整体移动数据目录，并检查配置中的绝对缓存、临时和日志路径。

退出可以每次询问、保留数据或清理默认缓存。清除应用数据每次单独确认，已下载的文件与自定义目录安全保留。若数据目录与下载目录重叠将拒绝清理，防止误删已下载内容。

“全选当前筛选结果”覆盖完整筛选结果；“下载整个对话”覆盖全部媒体并从最新消息扫描。取消或失败不会将部分结果标为完整。单次扫描上限为 100000 项。

批量重下创建仅包含选中消息的新任务，关闭相册展开；已完成项覆盖登记的最终目标，跳过或失败项的同名文件编号保存。旧任务缺少账号或对话类型信息时，请从当前对话重新选择下载；本地历史记录仍保留。
