# 创建下载任务

难度：中级 · 前置：账号登录

## 方式一：从对话中选集下载（推荐）

登录后，打开「对话」页，以双面板形式浏览所有对话和媒体文件。

### 选择对话

- 左侧面板显示全部对话（私聊 / 群组 / 频道），支持：
  - **搜索**：按标题或用户名搜索，支持正则表达式
  - **类型过滤**：全部 / 私聊 / 群组 / 频道
  - **排序**：按最近消息时间或按标题字母序
- 点击对话条目，右侧面板加载该对话的媒体文件

### 浏览与筛选媒体

右侧面板以卡片网格展示媒体文件，支持以下筛选：

| 筛选条件 | 说明 |
| --- | --- |
| 关键词 | 搜索文件名或消息说明文字 |
| 类型 | 视频 / 图片 / 音频 / 文件（可多选） |
| 扩展名 | 如 `mp4, jpg`（逗号分隔） |
| 大小范围 | 最小 MB ~ 最大 MB |

媒体卡片显示缩略图（图片/视频有清晰预览）、文件名、大小、扩展名和日期。点击卡片可勾选/取消勾选。

### 媒体布局切换

右侧面板顶部支持三种布局模式切换：

| 布局 | 说明 |
| --- | --- |
| 网格 | 等宽卡片网格，适合快速浏览 |
| 瀑布流 | 按原始比例排列，适合图片预览 |
| 时间流 | 按消息时间线排列，带日期分组 |

### 已下载标记与打开

- 媒体卡片右下角显示 {{icon:check-circle}} 标记表示该文件已下载
- **双击**已下载的媒体卡片可直接用系统默认程序打开文件
- 点击「已下载」标记可查看文件路径，或打开所在目录

### 下载前统一比对

单项下载、下载选中和下载整个对话共用一个确认窗口，分别显示候选、清单已记录、本地另有和预计下载数量，同一媒体只计算一次。重名会分组展示数量、消息日期、大小和本地路径，无法明确来源的项目保留待下载。
### 创建下载任务

- 勾选需要的文件后，点击「下载选中」
- 在弹出的对话框中选择保存目录、可选的过滤/命名脚本
- 可选：下载整组相册 / 按 MIME 修正扩展名；默认严格下载选中范围
- 核对比对结果后点击「创建下载任务」，到「下载」页查看进度

> 也可点击单个卡片上的下载按钮直接下载该文件。

## 方式二：粘贴消息链接

适用于拥有可访问消息链接的场景：

1. 在 Telegram 中右键（或长按）包含媒体的消息 → **复制消息链接**：
   - 公开频道 / 群组：`https://t.me/频道名/消息ID`，如 `https://t.me/telegram/123`
   - 私有频道 / 群组：`https://t.me/c/内部ID/消息ID`，如 `https://t.me/c/1234567890/456`
2. 打开「下载」页，点击右上角「添加下载」
3. 在对话框中粘贴链接（**每行一条**），可一次粘贴多条
4. 选择保存目录、可选脚本，勾选选项，点击创建

> 私有频道链接要求当前登录的账号本身是该频道成员。

## 任务管理

「下载」页中每个任务卡片显示状态、总进度与进行中文件的实时进度：

| 状态 | 说明 | 可用操作 |
| --- | --- | --- |
| 排队中 / 下载中 | 正在解析或下载 | 暂停、取消 |
| 已暂停 | 进度已保留 | 恢复（断点续传）、取消 |
| 已完成 / 失败 / 已取消 | 终态 | 移除记录、继续下载未完成 |

### 断点续传

暂停或退出后，同一任务内完整保存的文件保留完成记录。恢复时跳过已完成项，未完成文件重新下载；当前实现不保留单个文件的字节级分片进度。

### 继续下载未完成文件

对于已完成但部分文件失败的任务，点击「继续下载」可仅重新下载状态为失败或未完成的文件，已成功的文件不会重复下载。

## 单文件操作

在任务卡片的文件列表中，右键点击任意文件行可执行以下操作：

| 操作 | 说明 |
| --- | --- |
| 重新下载 | 删除该文件的断点记录并重新下载 |
| 打开所在目录 | 在系统文件管理器中定位该文件 |
| 删除记录 | 仅从数据库移除记录，不删除磁盘文件 |
| 删除文件 | 删除磁盘文件并同步移除记录 |

## 媒体预览

### Lightbox 全屏预览

- 在对话页的媒体网格中，**单击**媒体卡片可打开 Lightbox 全屏预览
- 支持图片的缩放、拖拽、键盘左右切换
- 视频文件在 Lightbox 中可直接播放

### 视频播放器

- 视频卡片和 Lightbox 中均内置自定义视频播放器
- 支持播放控制：播放/暂停、进度拖拽、音量调节、全屏切换
- 已下载的视频支持本地播放；未下载的视频支持边下边播（需设置视频临时目录）
- 键盘快捷键：空格播放/暂停、左右方向键快进/快退 5 秒、F 全屏、Esc 退出

### 磁盘空间保护

在「设置 → 下载」中设置「磁盘使用率上限」（1%–99%，默认 90%），保存后对下次启动或恢复的任务生效。检查的是实际下载目录所在磁盘的整体使用率，也会考虑当前用户可用空间。开始下载前、每次写入前及下载期间都会检查；如果下一分片会超限，会提前停止。

触发后自动停止并等待并发下载收尾，本次任务显示「已完成」，同时提示停止原因和清单路径。已完整保存的文件保留，未完成的临时文件清理，不会写入清单。若文件保存或清单写入失败，任务显示失败；修复问题后重试，会核对本地已完成文件并补记清单。

已选清单时，完成项逐条追加至原清单；未选清单时，从首个文件完成起自动在下载目录生成 `tdl-media-对话类型-对话ID-任务ID.jsonl`，暂停、恢复或重启后继续追加同一份清单。混合多个对话的任务按对话分别记录，避免消息 ID 冲突。

清理空间后，导入对应清单，再选择原来的下载范围或消息链接创建新任务，清单中已完成的项目会自动跳过。清单只记录已完成项，不包含原任务完整的待下载范围；多个对话分别导入对应清单继续。没有新增完成文件或经核对的本地完成项时，不会生成空的自动清单。

## 文件命名

默认使用原始文件名，不添加对话或消息前缀。无法确认的重名文件自动追加 (1)、(2)，实际保存名不会替代原名参与来源比对。可显式使用手动重命名或命名脚本。

## 已下载清单

选择对话后打开「已下载清单」，选择本地媒体目录，点击「扫描并比对」。扫描结果显示匹配、未匹配和重名未确认数量；展开重名组可以核对消息日期、大小及本地相对路径。同名文件默认不收录，仅在确认来源匹配后收录。

点击「导出确认匹配项」后选择保存位置。清单只包含本地存在的确认匹配项，未匹配、未确认项不导出，匹配为零时不生成文件。导出时会再次检查本地文件。

以后下载时导入这份清单，软件直接跳过其中确认记录，无需选择跳过模式。本地视频上传并删除后，清单仍可使用。绑定清单后，本次完整保存成功的媒体会自动追加；失败、取消和临时文件不会追加。也可在下载窗口新建空清单，供首次下载记录成功项。上传是否完成由用户确认。

旧清单的待下载项及旧规则推断的本地匹配项会被忽略并提示重新扫描，避免误跳过。清单仅保存在本地，不包含会话凭证、访问哈希或媒体内容。
### 核对重名媒体的日期

重名默认不进入清单。只有能核实具体消息日期和对应文件时，才点击该项的「核对日期与文件」，选择大小一致的本地文件，并明确勾选已经核对内容及消息日期，再确认对应。确认只作用于这条消息及媒体；可以撤销确认。无法确定时建议保留待下载。导出时会重新检查日期、来源、文件存在性和大小。


新清单使用 .jsonl，成功保存的媒体逐条追加并落盘；兼容旧 .json 确认记录。清单旁的 .lock 为零字节协调文件。批量重下只包含选中消息，已完成项覆盖登记目标，跳过或失败项遇到重名时编号保存。
